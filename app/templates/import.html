Import certificates

You can import root / intermediate CAs as well as plain server or client certificates. The certificate field may contain several PEM certificates (e.g. fullchain.pem: cert + intermediate, or an intermediate + root chain). Each one is imported and issuer relationships are detected automatically. The private key is attached to the certificate it belongs to. A PKCS#12 file (.p12 / .pfx) can also be uploaded; enter its password in the password field.

  • The type of a plain certificate comes from its Extended Key Usage: serverAuth → server, only clientAuth → mTLS client.
  • Certificates from other CAs (e.g. Let's Encrypt) can be imported too: they are not linked to a CA, but their expiry is monitored.
  • A root CA can be imported without its key (offline root). Password-protected keys are stored unencrypted.
